# 七款游戏升级：4–6 岁本地验收版

目标用户：4–6 岁。快递站、找不同、数独保留原规则。本轮其余七款从短促的固定点击任务升级为可重复、有选择、有结果的独立游戏。

## 调研依据

- [ThinkFun Rush Hour Junior](https://www.thinkfun.com/en-US/products/educational-games/rush-hour-junior-76583)：40 个分级交通谜题。借鉴可理解的限制与先规划再执行，不复制关卡。
- [SmartGames Trucky 3](https://www.smartgames.eu/uk/one-player-games/trucky-3)：3–8 岁、48 个组合挑战。借鉴有限零件和空间组合，应用于拼桥。
- [Sago Mini Trucks & Diggers](https://sagomini.com/apps/trucks-and-diggers/)：六种工程机械、多种建造目标和动画反馈。借鉴车辆差异和有成果的操作。
- [ThinkFun Robot Turtles](https://ravensburger.com.au/products/thinkfun-robot-turtles)：面向学龄前的指令式游戏。借鉴排列、试走、修改，而非限时答题。

这些来源说明具体机制；“更适合本项目”的判断是设计推论，不能由宣传中的教育效益直接证明。

## 实现范围与验收门槛

| 游戏 | 旧问题（已核对代码） | 新体验 | 必须验证 |
|---|---|---|---|
| 排队 | 固定三种车，依次点掉 | 12 辆车池；3/4/5 辆的车票与前后关系，排队、撤回、检查 | 线索唯一确定顺序、随机选项、全部车辆可出现 |
| 修桥 | 三关都轮流放四块 | 4/6/8 格桥，长短桥板、备用板选择、材料匹配、可选双人轮流、试车 | 每题有解、无超出边界、支持失败后撤回 |
| 分类 | 单车依次分类 | 救援/工程/运输车、生活物品、多属性停车场 | 每个物品有明确分类、颜色与车型双条件正确 |
| 修车 | 固定消防车和固定三零件 | 六种车辆、2/3/4 项检修、工具选择、零件差异、试车 | 缺件与补件一致；车辆特征正确；答案不固定位置 |
| 红绿灯 | 只照着红绿颜色点 | 入门看灯停走；练习/挑战指挥双向车队，行人优先、队首救援车优先 | 行人过街时两车道等候；安全的普通车道允许自由选择；无时限失败 |
| 听指挥 | 固定三站，答案常驻 | 八站池、2/3/4 站听单、盖住、安排路线、重听、撤回 | 音频和路线一致、提示记数、完成保留路线 |
| 改道 | 选择一次没封路选项 | 4×4/5×5 地图，施工绕路、途中站点、画路线、试走 | 有解、邻接、不可穿墙、站点顺序、撤回后可完成 |

共通：三档直接选择、按账户只存偏好、全量预加载、56px 以上触控、横竖屏、返回逐级、无局面存档。选择页不创建记录；完成/返回/重开仅记录一次，卸载只释放监听器。完成画面保留原布局，暂停和后台停止动画。声音必须匹配新规则，不能让旧语音讲错任务。

新增素材优先复用已重绘的统一车辆与站点。动态零件、桥板、路口、地图使用可编辑组件；仅在需要不可替代的插画时调用生图。

## 最终实现

- 排队：每局从 12 辆车选择 3/4/5 辆；入门看图排队，练习/挑战用打乱的前后关系卡推理。错误前缀提示标出待调整的车位，撤回后才提示下一辆车。
- 修桥：4/6/8 格河面；练习和挑战有备用桥板，需要选择合适的长度组合，挑战同时匹配桥墩颜色。无可续接方案时提示撤回；原生成路径始终保证可解。双人模式通过交替提示协作，不识别人是谁。
- 分类：小车用途、生活物品、颜色＋车型三个任务；采用 10 种适合用途分类的车辆，以及 15 种食物、工具材料、图书玩具书包。礼物含义不明确，未纳入分类题。
- 修车：六种可检修车辆、2/3/4 个故障、三种工具与三种零件候选。不同车辆使用梯子、通风格栅、急救箱、货箱、挖斗、吊钩；候选与装车图形共用组件。
- 路口：入门看红绿灯；练习有两队各两辆车与一次行人通行，挑战两队各三辆车与两次行人通行，队首救护车优先。普通车道都安全时，孩子可以自由安排。放行有 800ms 小车/行人通过动画，暂停与家长面板冻结计时和画面。
- 听指挥：八站池，2/3/4 站路线；听、记、盖住、排列、重听和撤回。站名复用快递站音频片段拼成整条路线，车辆随用户选择。
- 改道：4×4/5×5 地图、随机施工、0/1/2 个顺序任务点，允许回头路与撤回；生成器保证存在路线。

七款均提供入门/练习/挑战，保存账户偏好、不保存局面。准备页不记局次；完成、返回、重开去重；卸载只释放监听器。暂停、静音、家长记录和全量资源准备复用现有能力。完成后保留成果，不自动进入下一题。其他三款游戏规则未改。

- `npm run test:workshop`：七款 × 三档 × 200 种子，合计 **4,200 局**。验证种子复现、题目变化、可解、错误操作、重复输入、撤回、完成锁定、资源覆盖、偏好校验和账户键隔离；排队覆盖全部 12 辆车。
- `outputs/workshop-browser-landscape-v2.txt`：1024×768，21 个组合完成，21 条完成记录且 ID 唯一，零脚本异常、零迟到媒体请求。发现听指挥预留控制区超高后修正；最终三档复测见 `outputs/workshop-listen-layout-final.txt`，高度 768、按钮全可见。
- `outputs/workshop-browser-portrait-v2.txt`：768×1024，21 个组合完成，21 条完成记录且 ID 唯一，零脚本异常、零迟到媒体请求。准备、游戏中、完成页均无横向溢出；游戏中显示按钮宽高均至少 56px。
- `outputs/workshop-feedback-result.txt`：行人动画暂停、车辆动画随家长面板冻结、防重复放行、防连点返回、退出后取消迟到回调、排队错序提示恢复、桥板死路提示、减少动态效果、修桥完成前后场景位置尺寸一致、完成后打开家长面板及模拟后台保留静态成果。
- `scripts/workshop-lifecycle-qa.js`：覆盖暂停输入保护、重复点击、分类首页返回、家长重开、刷新丢弃、完成后等待保留、浏览器后退丢弃与记录去重。首页测试等待 React 绑定点击后再操作，避免开发服务器初次 hydration 尚未结束时点击落空。
- 全部旧规则、数独、找不同、快递站回归，以及记录、局次、导航、资源、素材、TypeScript、新增组件 ESLint、生产构建通过。
- 浏览器测试通过请求拦截隔离陪玩记录，未写入或清空真实家庭记录。资源就绪后阻断 PNG/MP3/WAV 请求，七款各档仍可操作、完成。

新增规则和提示共 28 条启用 MP3；试听运行使用已下载文件，不调用在线 TTS。每款预加载约 1.28–2.28 MiB。没有增加运行 PNG，复用统一车辆/站点/货物；可变桥板、道路、工具与维修零件用组件绘制，不需要额外生成重复插画。
