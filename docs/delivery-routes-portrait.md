# 多站配送与全站 iPad 竖屏升级

本轮本地交付，不自动提交、推送或发布。面向 4–6 岁，由家长按孩子的情况调整。现有素材库、游戏规则主体、账户及记录 API/数据库结构不变。

## 使用入口

汽车快递站 → 顶部“家长面板” → 设置。

| 设置 | 范围 | 规则 |
| --- | --- | --- |
| 要送的货物 | 按任务 / 1–4 件 | 每件为一种不同货物，不是同种物品的数量题 |
| 要去的目的地 | 按任务 / 1–4 站 | 每站至少一件，因此站数不能大于货物数 |
| 额外货物 | 按任务 / 0–8 件 | 不包括订单货物，货架最多 12 件 |
| 额外目的地 | 按任务 / 0–6 个 | 不包括真实路线，候选最多 10 个 |

两个实际数量分别设置，不会修改另一项来自动凑出合法组合。不合法时显示原因，选车开局按钮禁用，提供“调整配送设置”。“还剩什么”的第 7、8 类任务需要至少两站。切换任务后重新计算合法性；“按任务”仍取原八个任务的数量和额外选项默认值。

数量偏好按账户保存，继续使用原设置键。旧配置补齐为两个“按任务”，不影响原来的额外数量。游戏中修改从下一整局生效，当前三份订单全部保持原设置；重开、再玩使用最新配置。只记偏好，不保存局面。

## 订单与剩余货物

- 每单明确生成 `deliveries: {stop, cargo[]}[]`。实际货物和真实站点各不重复，每件只分配一次，每站非空，数量尽量均衡。
- 4 件送 3 站为 2+1+1；收到两件的站点随种子变化。4 件送 2 站为 2+2。订单及干扰项都可用相同种子、历史和配置复现。
- 订单显示货物、依次到达的站点及每站分配的货物。站点候选只显示建筑、名称和已到状态，不带货物答案。
- 看单任务保持订单可见；记忆任务在“记好了”后隐藏，重看时再显示。扩大数量时调整含“两件/两个站”的任务名称，并显示实际件数和站数。
- 装齐货物后按原规则出发，到站点击一次卸下该站全部货物。路上、卸货、完成特效都使用本单分配，不再以货物数组下标推断。
- 剩余任务在每个非末站卸货后出题：剩一件时直接选择，剩两/三件时点击勾选，可取消，点“选好了”核对完整集合。少选、多选、选已送货物均不通过，不扣分。
- 剩余题保留完整原货架和已送货物，位置不变。装载勾选、已送货物特效不泄露剩余集合；提示逐步突出一件尚未选中的正确货物。
- 剩余题答对：额外目的地为 0 自动继续行驶，否则选下一站。已到站点在固定位置禁用。快速重复卸货、确认或完成不会重复推进。
- 一局仍为三份订单，显示“第 x/3 单 · 第 y/z 站”。完成后保留成果和操作入口。

## 语音与记录

货物和路线片段支持 1–4 个对象。订单语音先概括货物，再按顺序说明“先去/再去 + 站点 + 送上 + 该站货物”。只新增“送上”连接片段，重新生成“剩余货物”“下一站”两条数量中性语音，仍使用晓晓配音及原语速音量。不生成组合整句，不增加图片。配送预加载共 200 个资源，5,243,013 字节（约 5.000 MiB），新增片段和两条更新语音均在进入前准备。

新局次版本 `delivery-routes-v6`，配置版本 2，历史格式 2。压缩历史沿用冻结的货物/站点字典，长度从 1–2 扩到 1–4，兼容旧短记录。元数据记录实际数量、请求配置、实际额外数量、候选数和压缩历史，种子和任务 ID 沿用原字段；最大配置验证未超过 500 字符限制。旧 v5 记录仍按原字段显示，新记录显示实际件数/站数。

准备阶段不创建局次。完成一次，网站返回/重开未完成一次；刷新、关闭、原生后退不补交。离线重试继续使用同一记录 ID。设置改变不修改正在进行的局次元数据。

## 十款游戏的固定竖屏画面

- 共享 `useGameViewport` 和 `game-viewport.css` 管理游玩、暂停和完成画面。记录真实可视高度，兼容地址栏引起的高度变化和安全区。
- 使用当前页面的固定画面与局部样式，禁止游戏画面随单指滑动/滚轮上下移动。退出时恢复原滚动位置和样式，解绑监听；首页、任务/车辆/难度列表仍正常滚动。
- 家长面板、记录、订单重看等弹层为独立可滚动容器；排队拖动继续使用 Pointer Events。保留双指缩放，不禁用浏览器无障碍缩放。
- 游戏中横屏显示“请把 iPad 竖起来”，暂停语音、计时和动画，不丢局；回竖屏后主动点恢复。过小的分屏窗口给出扩大窗口提示；没有调用强制旋转 API。
- 货架四列，最多三行；目的地最多三行。优先压缩背景场景和留白，按钮至少 56px，不用整页缩放或裁掉必需操作来实现适配。
- 系统边缘手势、浏览器导航属于系统/浏览器控制范围，网页不承诺屏蔽。标准字号与正常缩放下按指定 iPad 尺寸验收；用户主动放大时允许浏览器辅助查看。

## 首页防拖动补充（2026-11-01）

根据真实 iPad 反馈，将固定视口范围扩展至游戏首页。原首页没有滚动锁，两列卡片的最小高度也超过一屏；现在首页使用可见视口高度，竖屏以两列五行显示全部十款游戏，并阻止单指整页拖动和回弹。首页不要求竖屏，也不触发游戏暂停提示。选车、选难度仍按原规则滚动，家长弹层保留独立滚动，双指缩放不拦截。

`scripts/home-viewport-qa.js` 验证七种竖屏尺寸（含 768×800 的较短可见区域）及 1024×768 横屏：十个入口均完整显示，无横向溢出，最小卡片高度约 100px；触摸滑动与滚轮不改变首页位置。模拟 12 条陪玩记录，弹层触摸滚动 285px；分类切换、进游戏后返回恢复分类、刷新及进入选择页释放首页锁均通过。

截图：`output/playwright/home-portrait.png`。类型、导航及共享视口 hook 静态检查通过。以上是桌面浏览器触摸模拟，真实 iPad Safari 地址栏伸缩、回弹和手感仍需更新后复测。

## 全部游戏页面固定与长按修复（2026-11-01）

按后续确认扩大范围：游戏首页、资源准备/失败重试、快递站欢迎/任务/选车、十款游戏的选择/游玩/完成画面全部使用固定可见视口。家长设置及陪玩记录允许弹层内部滚动；其余游戏弹层不滚动。离开游戏区域时恢复原有文档样式，不影响绘本等其他页面。

选车使用共享分页组件，每页最多八辆，保留车型分类、上次车型和清晰的上一页/下一页。首次打开默认显示上次车型所在页。快递站及五款支持全部车型的工坊入口可访问全部 20 辆；修车仅六辆适配车型。准备页翻页、筛选和选车不创建局次，正式开始规则不变。

触摸调查在浏览器中复现：按住并移动 22px 时，原防滚动的 `touchmove.preventDefault()` 会令后续原生点击缺失；纯静止长按能触发。现普通按钮以触摸/笔的 Pointer Events 释放事件确认，不限制按住时长，允许最多 28px 的移动且必须在原按钮内松手。按住时有描边反馈；移动过大、滑出按钮、多指、取消、失焦、隐藏页面、按钮被替换或禁用均取消。兼容点击被去重，鼠标和键盘保持原生操作。排队车辆仍由独立拖动逻辑处理。没有更改规则、音频、素材或记录接口。
