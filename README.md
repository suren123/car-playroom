# 汽车小任务

给 4 岁左右孩子与家长一起玩的 iPad 汽车网页游戏。由 Sites 的 OpenAI 账户登录控制访问；无需另设家庭账号或密码。需要网络，使用大图、少文字、预生成中文语音和短音效；不计时、不扣分、不排名，也不生成注意力或情绪能力评分。

## 游戏入口

游戏首页位于 `/game`，直接展示十款游戏，汽车快递站、小汽车排队、一起修桥排在最前。可按分类筛选，每款游戏有独立的 `/game/<id>` 路由。旧 `/game/library` 地址跳转到首页，并保留有效的分类筛选。

- **汽车快递站**：首页列表入口，也可以直接访问 `/game/delivery`。八个关卡模板，从看订单装货到视觉记忆、顺序记忆和记住剩余物品，每关三次配送。看好了再收起订单，可重看、求助、暂停和结束。

- **专注力小任务**：汽车分类、找不同、汽车数独、消防车听指挥。
- **规则与情绪小任务**：小汽车排队、红绿灯小司机、道路施工改道、修车小师傅、一起修桥。

分类从颜色、同车型逐步到用途；分类的循序练习从简单开始，连续两局顺利完成后建议尝试下一步，由家长或孩子主动选择；“再玩一局”保持当前阶段。分类也可在家长入口固定选择简单或挑战。

找不同每次进入先选 **入门、练习、挑战**：每边分别 4 辆（2×2）、6 辆（3 列×2 行）、9 辆（3×3），寻找 1、2、3 处不同。使用消防车、救护车、公交车、货车、挖掘机、吊车 PNG，差异只改变车型；相同位置保持完全一致。点击任意一边，两边对应位置同时标记，答错不扣分、重复点击不计数。提示沿用逐级观察/突出位置/手指示范，找到一处即清除临时提示。找齐后车阵和全部标记原位保留，主动选择再玩同档新题或换难度。

找不同只按账户保存档位偏好；新偏好优先，旧简单或循序阶段 0→练习，旧挑战或循序阶段 1→挑战，无有效偏好默认入门。选择页及图片加载阶段不创建局次，失败可重试；刷新或重新进入回到选择页。首页专属图标用两块小面板展示消防车/公交车与消防车/货车，黄色圈标出第二组对应车辆。完成、换难度、返回与重开每局最多提交一次记录，新记录附带档位、车辆数、差异数、版本和种子，历史记录保持原解释。

汽车数独每次进入先选 **2×2 · 入门、3×3 · 练习、4×4 · 挑战**，分别留 2、3、6 个空位，只要求每行每列不重复，没有小方框规则或自动进阶。每题唯一解，可以仅用行列排除完成，每行每列至少保留一辆已知小车。先点空位再选车，开局及填对后自动选中一个空位；已知车辆与填对车辆不可修改，答错不填入、不扣分。提示先突出行列，再指出正确车辆；换空位或填对即重置。填完后完整棋盘原位保留，主动选择再玩同尺寸新题或换难度。

数独只按账户保存尺寸偏好，刷新和重新进入仍回到选择页。首次迁移旧简单→2×2、挑战→4×4，循序阶段 0/1→2×2、2/3→4×4；新尺寸优先，无有效偏好默认 2×2。四种 PNG 为消防车、公交车、挖掘机、货车，首页数独卡片用同一素材组成专属 2×2 填空图标。开局先等待图片加载，失败可重试，准备完成才创建记录。

数独增加停车场庆典与行列反馈：填对时车辆轻轻落位，新完成的行列亮起一次；全部完成后边框依次亮灯，外围星星和彩纸约 3 秒后消失，下方小车车队停住。完成前后棋盘位置、尺寸一致，按钮立即可用。复用预加载图片和完成语音，无新增媒体下载。过程动效随暂停冻结；完成庆典切后台或打开家长面板后直接保留静态成果，减少动态效果模式也直接显示静态成果。动效不影响记录提交或生成规则。

每局都有提示、暂停和返回入口，家长面板提供重新开始这局；数独和找不同的家长面板不再重复提供难度或进阶设置。数独完成、返回、换难度与重开每局最多提交一次记录，带实际尺寸、空格数、行列规则、版本和随机种子；旧记录保持原解释。

排队游戏先让孩子选一辆自己的车，选车成功才创建局次记录；选车页高亮上次选择。教学局先走，后续轮到第二位或第三位。提前点车只提示等待，不改变本局顺序。其他两辆由大人操作，屏幕无法识别实际是谁点了按钮。

家长模式自动记录每局完成或主动结束、选错、提前点击、提示、重试、暂停次数。记录同步至站点 D1 数据库，直到家长手动清空；不保存孩子姓名、照片、录音或逐次点击轨迹，也不根据点击推断真实情绪或独立能力。网络故障时未同步记录会留在本机浏览器，恢复网络后可在家长模式重试。

游戏不保存未完成局面。返回首页、刷新、关闭或重新进入游戏时重新开始；当前页面内暂停或切后台后，在页面未被系统重新加载的情况下可以恢复原局。十款游戏的暂停画面只提供恢复按钮，顶部“返回”结束未完成当局并退回上一级页面，家长面板可重新开始。快递站每次进入都可选择任务和车辆。

声音、上次玩法和车辆、难度与进阶偏好继续保留。陪玩记录独立保存：完成、点击返回和重开会提交记录；刷新、关闭或浏览器后退丢弃未完成局，不在卸载时补交记录。同一游戏可以在多个标签页独立开局。升级时仅清理当前账户十款游戏的旧局面快照和旧锁，不删除偏好、历史记录或待同步记录。存储不可用时可继续玩，但设置或陪玩记录可能无法保存。如果离线开局时无法确认记录代次，该局的记录不会自动上传，避免清空后的旧记录重新出现。

## 进入前准备资源

点击任一游戏后，先显示统一准备页，下载并校验该游戏所有难度、车辆、关卡、提示、完成画面、语音和音效。全部成功后自动进入原来的欢迎、选择或游戏页面；当前静音也会准备声音。下载进度按真实字节显示，下载完后等待图片与音频解码校验。准备阶段不创建陪玩记录，切后台时等待回到前台再进入。

资源最多四项并行，单个请求连续 20 秒没有进展就失败。失败页只提供重试和返回，不允许跳过资源；重试保留成功部分。准备中返回回到来源首页并保留分类，取消请求和迟到回调；进入后的逐级返回规则不变。

游戏图片、语音使用已准备的对象 URL，音效使用已解码缓冲，不在操作时重复请求原文件。退出后释放本局入口持有的图片、对象 URL 与音效数据。静态资源另存入专用 `car-playroom-resources-v1` Cache Storage，共用资源可跨游戏复用；每个文件以 SHA-256 内容版本区分，读取时检查长度、内容和可解码性。缓存不可用或写入失败时仍可使用本次内存资源，不影响进入。

资源缓存不包含登录信息、API 响应、家长记录或游戏局面，不清空其他浏览器数据。没有引入 Service Worker，不保证断网后重新打开网站；已进入游戏的图片、语音不再依赖网络，记录仍沿用原有离线重试机制。浏览器的声音播放授权独立于资源下载，必要时点击声音入口开启。

资源清单由 `scripts/game-resource-catalog.mjs` 按游戏定义，通过 `npm run resources:generate` 生成文件大小与内容哈希。开发启动和生产构建都会生成清单，`check:assets` 检查清单是否过期，`test:resources` 检查语音覆盖、加载队列、重试与取消。添加新素材或提示时应同步扩充所属游戏清单及覆盖测试。当前快递站完整资源约 3.24 MiB，其余单款约 0.46–0.81 MiB，共用缓存命中后实际下载更少。

## 逐级返回

十款游戏左上角统一为左箭头“返回”，触摸区域至少 56px，并防止双击跨过多层。按当前页面确定上一级，不直接调用浏览器后退：

- 快递站：游戏或完成画面 → 选车 → 选任务 → 欢迎页 → 游戏首页。
- 数独、找不同：游戏或完成画面 → 难度选择 → 游戏首页。
- 排队：游戏或完成画面 → 选车 → 游戏首页。未完成时返回不推进轮次；选车页不创建记录，再次选车开新局。
- 分类、修车、修桥、红绿灯、听指挥、道路改道：返回游戏首页。

装货、行驶、卸货等局内步骤不作为可回退页面。返回无需确认，不恢复旧局面，保留任务、车辆、难度偏好；家长、声音、示范弹层仍使用自己的关闭按钮。明确的“返回首页”按钮直接回首页，“换难度”和“再玩一局”保留原功能。

首页来源分类只放在当前标签页的导航状态中；返回最终首页恢复原分类，直接打开链接则回完整首页。快递站准备页继续使用 `?step=levels`、`?step=cars`，通过替换当前游戏历史条目避免往返循环；开局保持选车地址，刷新回选车，不保存配送。浏览器原生后退不被拦截，不补交未完成记录；重新前进不恢复旧局。图片加载途中返回会取消后续开局，停止语音和局内计时。

返回规则见 `lib/game-navigation.ts`，来源分类通过 `hooks/use-game-navigation.ts` 传递，共用按钮位于 `components/game-back-button.tsx`。运行 `npm run test:navigation` 检查十款游戏的层级映射与导航来源隔离。

## iPad 使用

1. 用 Safari 打开 [https://haoran.awarejam67.chatgpt.site/game](https://haoran.awarejam67.chatgpt.site/game)。站点保留 Sites 的私密访问，请家长先登录创建网站时使用的 ChatGPT 账号。
2. OpenAI 登录后进入游戏；访问权限由创建 Sites 的 OpenAI 账户和 Sites 私密访问设置控制。
3. 在 Safari 点“共享 → 添加到主屏幕”。如果出现“作为网页 App 打开”，将其打开，再点“添加”。
4. 从主屏幕图标进入，确认登录、语音和横竖屏显示。Safari 与主屏幕网页 App 的登录状态可能不同，必要时重新登录。

根地址 `/` 会跳到 `/game`；旧域名会跳转到新域名。更换域名后需在新域名重新通过 OpenAI 账户登录，并建议用新地址重新添加主屏幕图标。提示使用预生成的中文女声；快递站提供全站静音、语音和音效设置。线下还可以拿真实玩具车练习轮流和送货。

## 本地开发

项目使用 React、Vinext、Cloudflare Worker、D1 与 Drizzle。Node.js 22.13 或以上。安装依赖后执行 `npm run db:generate`（仅在改动数据库结构时）、`npm run build`、本地 D1 迁移，再执行 `npm start`。本地迁移命令见 Sites Vinext starter 文档。

主要代码：`components/playroom.tsx`（大厅与原有游戏）、`components/difference-game.tsx`（找不同选择、车阵与完成画面）、`components/sudoku-game.tsx`（数独选择、棋盘、完成与局次生命周期）、`lib/replay-games.ts`（分类、找不同及行列数独规则）、`lib/sudoku-preferences.ts`（尺寸偏好迁移）、`components/road-games.tsx`（四款道路游戏）、`components/legacy-game.tsx`（修车与修桥）、`games/delivery/`（快递站规则与场景）、`games/vehicle-catalog.ts`（车辆目录）、`lib/records-api.ts`（家长记录接口）、`lib/speech.ts`（语音与音效播放）。

图片素材：60 张透明 PNG 原图放在 `assets/illustrations/individual/png/`。运行时导出位于 `public/assets/illustrations/v1/`，语义映射位于 `games/illustration-assets.ts`，可用 `npm run assets:export` 重新生成（需 Python Pillow）。快递站、汽车数独与找不同使用该素材组；依赖车辆动态换色的旧分类游戏继续使用 SVG。

## 语音素材

固定提示音频保存在 `public/audio/`，对应文字与声音参数见 `manifest.json`。使用项目本地 `.venv-edge-tts` 环境中的 `edge-tts` 生成；该工具需要联网调用 Microsoft Edge 在线语音服务，但不需要 Azure 登录。重新生成：`python -m venv .venv-edge-tts`、`.venv-edge-tts\Scripts\python.exe -m pip install -r scripts/requirements-audio.txt`，然后运行 `.venv-edge-tts\Scripts\python.exe scripts/generate-game-audio.py`。

快递站新增语音使用 `scripts/generate-delivery-audio.py` 增量生成固定提示、可复用的货物／站点名称和连接词，并更新 `lib/delivery-voice.json`。进入游戏前预加载，订单与路线在内存中拼成一段 WAV 播放，不再为每种组合保存整句录音。新增货物或站点只需补充名称片段，不必生成全部排列组合。`scripts/generate-effects.py` 生成短音效合包及索引。素材的来源、代码位置和状态见 `docs/asset-catalog.md`。运行游戏时无需连接语音生成服务。找不同的完成语音可用 `scripts/generate-game-audio.py --only difference-complete` 单独生成。数独复用 `sudoku-tutorial.mp3` 的行列说明，旧小方框语音已停用。新增提示可用 `scripts/generate-game-audio.py --only sudoku-row-column sudoku-vehicle sudoku-conflict sudoku-observe sudoku-complete` 单独生成。

`/game` 使用 OpenAI 注入的已登录账户身份验证；Sites 的私密访问层保护页面和记录 API。记录写入和清空还校验同源请求。此项目不保存 OpenAI 账户凭证，也不设置额外家庭密码。

## 检查

- `npm run test:rules`
- `npm run test:rounds`
- `npm run test:resources`
- `npm run test:navigation`
- `npm run check:assets`
- `npm run test:records`（使用独立的内存数据库，不清空本机记录）
- `node node_modules/typescript/bin/tsc --noEmit`
- 本地 D1 迁移及预览启动后可运行 `node scripts/test-records-local.mjs`；此脚本会清空**本地测试数据库**中的记录。

浏览器与设备检查结果记录在 `QA.md`。游戏用于亲子陪玩，不用于诊断或保证改善注意力与情绪调节能力。
